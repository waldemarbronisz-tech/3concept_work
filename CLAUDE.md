Wewnętrzna platforma webowa firmy 3Concept (realizacja budów, czas pracy,
przestoje, dokumenty, zamówienia). Faza beta: tylko dane fikcyjne.

- Wymagania biznesowe: [PROJECT.md](PROJECT.md) — przeczytaj przed każdą
  większą zmianą; zasady pracy w §32.
- Aktualny plan i model danych MVP: [docs/PLAN_MVP.md](docs/PLAN_MVP.md).
- Decyzje (D1–D10 i otwarte): [docs/PLAN_MVP.md §4](docs/PLAN_MVP.md); roadmapa: [docs/ROADMAP.md](docs/ROADMAP.md); wygląd: [docs/UI_STYLE.md](docs/UI_STYLE.md).
- Po zmianie: `npm run check` (lint, typecheck, format, testy) i `npm run build`.

Nie wymyślaj zasad płacowych, prawnych ani księgowych — pytaj.
Nie implementuj delegacji, premii ani AI przed ich milestone'em.
